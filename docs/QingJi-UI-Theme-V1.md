# 轻记 1.2.0 界面与主题

## 布局

参考鲨鱼记账官网公开截图的顶部月度收支、按天明细、圆形分类与中间记账入口。保留轻记名称、资产、退款、预算、攒钱和备份功能，未使用其品牌标识或图片。公开参考：https://www.shayujizhang.com/。

| 页面 | 内容 |
| --- | --- |
| 明细 | 主题色汇总区、月份切换、收入/净支出/结余、预算和资产入口、按日期分组账单、每日汇总、搜索与分页 |
| 图表 | 原日/周/月/年/自定义分析，图表及筛选随主题适配 |
| 中间记账 | 支出/收入、五列圆形分类、金额键盘、付款/到账资产、余额开关和预览、日期/时间/备注、连续记账 |
| 资产 | 银行卡/微信/支付宝等账户、总资产、账户详情、转账与余额校准 |
| 我的 | 主题与外观、预算与攒钱、分类管理、提醒、完整备份与恢复 |

金额键盘保留整数分入库，最多八位整数、两位小数；空金额和0不可保存。可退格、清空，不进行浮点运算。退款仍关联原支出，旧账只关联资产时仍保留关闭余额联动的状态。

## 主题

| 预设 | 色值 |
| --- | --- |
| 暖阳黄（默认） | #FFDA63 |
| 森林绿 | #78BE9D |
| 海盐蓝 | #80B2ED |
| 暮光紫 | #B39BE5 |
| 玫瑰粉 | #EA9CB5 |

另支持输入#RRGGBB。通过DataStore保存，跟随系统/浅色/深色独立于颜色选择；改变设置立即刷新。浅色采用主题汇总背景，深色降低背景明度；按钮、图表等主色在保留色相基础上调整到与表面至少4.5:1的对比度。主色与汇总区文字选择深色、白色或必要时纯黑，以保持至少4.5:1。

完整备份schema2新增可选settings.accent字段；原schema1/2缺省时默认暖阳黄，非法颜色拒绝导入。数据库仍为Room version2，包名和签名不变，versionCode提升为3。

## 交付与验证边界

QingJi-UI-1.2.0.html为可交互主题预览，包含示例明细、记账和资产界面；并非安卓截图，也不保存真实账单。浏览器内的颜色偏好与手机应用设置相互独立。

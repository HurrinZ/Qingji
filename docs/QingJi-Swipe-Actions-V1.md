# 首页账单左滑 · 1.3.1

| 操作 | 结果 |
| --- | --- |
| 账单左滑 | 露出备注、删除两个按钮 |
| 点备注 | 只编辑该账单备注，保存后留在首页 |
| 点删除 | 软删除账单，联动余额恢复，提供短暂撤销 |
| 点撤销 | 恢复原账单和余额 |
| 右滑/点已展开账单 | 收起按钮 |
| 纵向滑动 | 正常滚动账单 |

左滑仅展开按钮，不以滑动距离触发删除。同一时间只保留一行展开。无障碍自定义操作也可直接触发备注和删除。

删除与快速备注在首页操作，编辑输入页不再重复放置删除按钮。不给用户显示详细失败原因，仅保留“未删除/未保存”等简短状态。已有退款关联、归档账户保护不变；不会因这次界面改动产生孤立退款或非零归档余额。

删除保留数据库记录的软删除时间与递增revision；撤销仍复用仓库校验。备注在事务内读取最新记录后只修改note、updatedAt和revision，避免旧编辑快照覆盖金额或账户；已删除账单不能通过备注重新出现。

QingJi-UI-1.3.1.html是带示例数据的交互预览，可鼠标拖动或触屏左滑；不写入安卓账本。真实构建与验证范围见TEST-REPORT.md。

# 轻记 1.3 · 快速输入

| 输入 | 常用项 | 按需展开 |
| --- | --- | --- |
| 记账 | 分类、金额、账户、日期 | 备注；更多中的时间、连续记账、同步余额、编辑时退款/删除 |
| 添加资产 | 类型图标、余额 | 铅笔修改自动生成的名称 |
| 转账 | 转出/转入账户、金额 | 日期、备注 |
| 校准 | 实际余额、前后对照 | 备注 |

键盘和保存固定在底部。上方表单可单独滚动；长分类列表与展开更多时不会把保存按钮推到页面外。金额输入不使用浮点计算，仍按整数分保存。

新账户名称依据类型自动填写，存在同名使用中账户时自动添加序号。新增可保存零余额；校准空值禁用保存，需要明确输入0才能校准到0。转账为同账户或未填写金额时禁用保存。

说明压缩到信息图标中，负余额和旧账“仅关联”状态保留可见提示。旧账不会因界面改动默认扣减资产。

## 图标与图表

微信/支付宝采用Simple Icons矢量路径，分别保留绿色和蓝色。图标不会因主题变更被统一着色。银行卡使用银行图形，现金使用纸币图形，其他使用钱包图形。资产列表、记账选账户、转账和编辑资产均复用同一图标。

图标来源（2026-11-09获取）：

- https://github.com/simple-icons/simple-icons/blob/develop/icons/wechat.svg
- https://github.com/simple-icons/simple-icons/blob/develop/icons/alipay.svg
- https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md

许可证：CC0-1.0，完整文本在licenses/Simple-Icons-CC0.txt。品牌图标用于标识用户手工记录的账户类型；不代表支付平台接入。

资产环形图按类型汇总正余额，排除归档、0和负余额；有负余额时明确标示“正余额分布”，并提示负余额账户数。总资产继续包含使用中账户的负数。图例包含名称及百分比，不仅靠颜色识别。

## 交付

QingJi-UI-1.3.0.html用于体验三种快速输入面板，使用示例数据。与原生安卓运行不同，预览只在页面内模拟保存；关闭或刷新不会写入手机账本。原生版本保持包名和签名，versionCode=4，数据库仍为2。

真实验证结果见TEST-REPORT.md。没有可用安卓真机时，不把HTML预览检查视为原生UI实测。
